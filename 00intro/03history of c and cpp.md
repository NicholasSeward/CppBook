# History of C and C++

C++ did not appear from nowhere. It grew out of [C](https://en.wikipedia.org/wiki/C_(programming_language)), which grew out of earlier systems languages when computers were smaller and every byte mattered.

## C

C was developed in the early 1970s at Bell Labs. It became the language of Unix and much systems software. C is small, fast, and close to the machine. It also leaves many safety checks to the programmer.

You will still see C ideas everywhere in C++: functions, structs, pointers, and manual memory management (later topics).

## C++

Bjarne Stroustrup started **C with Classes** in 1979. The name **C++** appeared in 1983. The `++` is the increment operator: C with one step beyond.

C++ added:

- stronger types and overloading
- classes and object-oriented programming
- templates and generic programming
- a much larger standard library over time

C++ is often described as a **multi-paradigm** language. You can write C-style code, object-oriented code, generic code, and more in the same project.

## Standards over time

Both C and C++ are standardized. New **standards** (C++11, C++14, C++17, C++20, C++23, C++26) add features and clarify rules. Compilers implement specific standard versions.

HISTORY: C++ was intentionally designed to remain backward compatible with most existing C and C++ code. This choice has resulted in some unusual decisions, but it is a key reason C++ became such a widely used foundational language.

## Why learn C++ today

C++ is still used for games, browsers, databases, embedded systems, high performance servers, and tools you use every day. Learning C++ teaches how computers, memory, and performance really behave, even if you later use other languages.
