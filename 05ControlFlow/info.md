# Control Flow (index)

Programs run line by line from `main`, unless a **control flow** statement changes the path. This folder covers branching, loops, and stopping execution.

Builds on [logical operators](../06Operators/07logical%20operators.md) and [relational operators](../06Operators/06relational%20operators.md).
